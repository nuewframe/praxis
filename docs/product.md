# Praxis

## Vision

A team can trust what an agent produced without re-deriving it.

## Mission

Make execution fidelity a property **computed from the record**, rather than a claim made by
whoever produced the artifact.

## Who this is for

**The team building digital products** — engineers, designers and product managers working
through an LLM coding agent.

That is the primary persona, and it is known before anything is framed: it is the reason
discovery is happening at all. Everyone else is discovered. The work within a frame is what
identifies them, and each one names what surfaced it.

## The problem it exists to close

GenAI coding agents improvise structure, skip discovery, drift scope, and produce
plausible-looking artifacts with nothing behind them. **The artifact looks identical whether
the agent reasoned hard or pattern-matched a template**, so trust in it has to be granted
rather than earned.

Praxis closes that gap by making fidelity something a checker computes.

## Where everything else is

This file is the **anchor**. It holds what the product is for and who for, and deliberately
holds nothing that the record already holds — a second copy is the one that goes stale, and
most of what used to be here had.

| Question | Ask |
|---|---|
| What does this repository already know? | `praxis truth` |
| What governs it, and what does every word mean? | `praxis schema` · `praxis schema --print` |
| What can be started right now, and what blocks the rest? | `praxis ready` |
| What does it ship as instruction, and what asked for each piece? | `praxis audit-surfaces` |
| What does it guarantee, and what keeps each guarantee? | `praxis check-invariants` |
| Which declared rules have never been shown to fire? | `praxis prove` |
| Where does the product stand right now? | `praxis dashboard` |

The problem, the capabilities, the slices, the decisions and the findings are records under
[`praxis/`](../praxis/). The published set for a version is
[`docs/releases/`](releases/), regenerated whole and never edited in place.

## Adopting it

`skills/adopt-the-method/` — nothing is copied. The method's vocabulary and its gate travel
with the engine, and a repository extends them without owning a version of them.
